# Wardley maps (example plugin)

A complete example of a third-party notation plugin. It shows:

- a notation pack (element types, relationships, a viewpoint, validity rules, property-driven colours),
- a validator that understands the notation (an "evolves to" link must move right),
- a side panel rendered from the model.

To try it, copy this folder to `~/.vastitecture/plugins/wardley` and press **Rescan plugin folders**
on the Plugins page. In the web build, use **Install from files…** and select `plugin.json` and
`index.js` together.
